# Babuza

*閱讀其他語言版本： [English](README.md), [繁體中文](README.zh-TW.md).*

## 專案簡介

Babuza 是一個基於 etcd 的 Raft 共識演算法庫，專為開發分散式系統而設計。本庫提供多種可客製化元件，讓開發者能更輕鬆地實作基於 Raft 共識的分散式軟體。

## 核心特色

- **高度模組化架構**：各元件可獨立使用或組合
- **基於 etcd Raft**：建立在穩定且經過生產環境驗證的 etcd Raft 模組上
- **可客製化元件**：提供多種可擴展的核心元件
- **簡化分散式系統開發**：降低實作分散式一致性的複雜度

## 主要元件與技術創新

Babuza 由以下核心元件組成，每個元件都有其獨特的實現和技術創新：

### 預寫式日誌 (WAL)

持久化 Raft 日誌，確保系統故障恢復時的資料完整性。特別優化的 BabuzaWAL 設計只在記憶體中儲存日誌偏移量，顯著降低記憶體消耗，適合長時間運行且產生大量日誌的系統。

### 快照機制 (Snapshot)

提供完整、安全、高效的分散式狀態儲存解決方案。支援持久型和揮發性儲存選項，實現安全的分塊傳輸、CRC 完整性檢查和 Snappy 壓縮，確保大型狀態資料的可靠恢復。

### 傳輸層 (Transport)

高效的節點間通訊實現，支援多種協議（HTTP/TCP）。提供智能流量控制、節點動態管理和安全通訊支援，適應從單機測試到大規模分散式系統的各種部署場景。

### 狀態機系統 (State Machine)

提供記憶型與磁碟型兩種實現，適合不同資料規模和持久性需求。統一的 Apply/Snapshot/Restore 介面，支援並發快照和多種操作模式，為開發者提供靈活的狀態管理選擇。

### 會話管理 (Session)

實現完整的操作冪等性保障機制，透過會話識別與追蹤確保每個操作只執行一次。支援 LRU、過期和無操作等多種會話管理策略，適應不同的系統需求和資源限制。

### 叢集管理 (Cluster)

支援動態節點加入和離開，簡化叢集配置和管理。包含強大的測試框架可模擬網路分割、節點失效和領導者選舉等各種分散式故障情境，確保系統的強韌性。

## 實驗性功能

### Multi-Raft 實作 (實驗階段)

位於 `raft/experimental/` 目錄下的 Multi-Raft 實作是一個實驗性功能，提供了在單一程序中管理多個 Raft 群組的能力。此實作包含：

- **Store 管理**：多個 Raft 群組的統一儲存管理
- **Replica 協調**：高效的副本管理和協調機制
- **動態群組管理**：支援 Raft 群組的動態創建和銷毀
- **資源最佳化**：共享底層資源以降低記憶體和 CPU 消耗

**注意**：此功能仍在實驗階段，API 可能會有重大變更，不建議在生產環境中使用。

## 使用案例

Babuza 適用於需要強一致性和高可用性的分散式系統，例如：

- 分散式鍵值儲存
- 分散式資料庫
- 配置中心
- 分散式鎖服務
- 任務排程系統
